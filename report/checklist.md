# Проверка требований

| Требование | Материал или статус |
|---|---|
| Вариант 4, Windows Mutex, асимметрия | src/main.cpp и src/platform.hpp |
| Параметры без перекомпиляции | Аргументы, --help, README |
| Номер и TID, состояния | Журнал и workers в JSON |
| Потокобезопасный журнал | os::Lock logger, отдельный CRITICAL_SECTION |
| Инварианты и нулевой итог | Context::check, итоговый JSON; в 48 portable опытах нарушений нет |
| Ошибки, тайм-ауты, освобождение | Проверки WinAPI, RAII, Event STOP и join |
| Ограничение длительности | --duration-ms, затем до 5 с на остановку |
| Индивидуальные значения | ID=027, SEED=3619, C=235 |
| 5/7 философов, THINK=2/15 мс | Матрица 16 конфигураций с контрольным ordered |
| Не менее трёх запусков | 48 исходных JSON и manifest |
| Настоящие измерения Windows | Не выполнены; требуется scripts/windows.ps1 на Windows |
| Два графика и исходники | throughput/waiting PNG и SVG, analyze.py, JSON |
| Схемы и исходники | diagrams/architecture DOT и Mermaid, PNG и SVG |
| Таблицы времени и профиля | summary.csv, workers.csv и раздел 13 отчёта |
| Обоснование отсутствия deadlock | Раздел 8 отчёта и report/design.md |
| Голодание и длительное ожидание | Ограничения FIFO, максимальное ожидание, тест тайм-аутов |
| Git до реализации и четыре этапа | Локальная реальная история; этапы фиксируются последовательно |
| Регулярные push и доступ преподавателю | Не выполнены; remote не задан |
| Все разделы отчёта и приложения | report.docx и report.md |
| Поля титульного листа | Требуют ФИО, группу, учреждение и преподавателя |
| Использование ИИ | Приложение А содержит фактическое описание |
| Дополнительные параметры и защита | Выполняются с преподавателем; пример в README |

Материалы не следует сдавать как полностью завершённую Windows-лабораторную до выполнения отмеченных пунктов. Историю удалённых публикаций и результаты Windows не нужно имитировать.
